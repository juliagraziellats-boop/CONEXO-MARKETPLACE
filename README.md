# Tema-5-Marketplace de Serviços Locais - Economia Colaborativa

O CONEXO é uma plataforma que conecta clientes e prestadores de serviços.
O cliente poderá procurar um serviço e solicitar um orçamento, enquanto o prestador poderá se cadastrar e receber essas solicitações.
O sistema também permitirá troca de mensagens, avaliações, notificações e acompanhamento dos orçamentos.
Além disso, os administradores poderão gerenciar os usuários e consultar relatórios sobre os serviços e orçamentos.
